# NESTA — РУКОВОДСТВО ПО МОБИЛЬНОМУ ПРИЛОЖЕНИЮ (PWA & CAPACITOR)

Платформа **NESTA** спроектирована по принципу **Mobile-First** и поддерживает два полноценных способа развертывания на мобильных устройствах:
1. **Progressive Web App (PWA)** — мгновенная установка без магазинов приложений с офлайн-доступом и полноэкранным режимом Standalone.
2. **Нативное мобильное приложение (Capacitor iOS & Android)** — сборка в нативный `.apk` / `.aab` для Google Play и Xcode-проект для App Store / TestFlight.

---

## 1. Возможности мобильного интерфейса NESTA

- **Нативная нижняя панель навигации (Bottom Navigation Bar)**:
  - 🏠 **Главная** — персонализированная сводка по сроку беременности или возрасту малыша.
  - 🤰 **3D-Малыш** — интерактивная 3D-модель плода с поддержкой сенсорного вращения на 360° и pinch-to-zoom жестов.
  - ➕ **Кнопка быстрого действия (FAB)** — центральная плавающая кнопка, открывающая мобильный шторку действий (Action Sheet).
  - ✨ **AI-Чат** — доказательный ассистент с мгновенным доступом к расшифровке анализов и симптомов.
  - 📚 **Библиотека** — клиническая база знаний ВОЗ и МЗ РК.
- **Шторка быстрых действий (Mobile Action Sheet)**:
  - 💓 Быстрый запуск счётчика шевелений Cardiff «считай до 10».
  - 🍼 Фиксация кормлений, сна, подгузников и замера температуры.
  - 🚨 Экстренный вызов скорой помощи **103** и единого номера **112**.
  - 📄 Быстрая загрузка фото УЗИ или результатов анализов с камеры смартфона.
- **Поддержка Safe Areas (Вырезы экрана, Dynamic Island и Home Bar)**:
  - `viewport-fit=cover` и отступы `env(safe-area-inset-bottom)` гарантируют, что элементы интерфейса не перекрываются полосой жестов iPhone или шторкой Android.
- **Встроенный симулятор мобильного устройства**:
  - На десктопе в верхней панели доступна кнопка **«Мобильный вид»**, позволяющая протестировать поведение приложения в точном корпусе смартфона.

## 2. Установка как PWA (Без App Store и Google Play)

### На iPhone / iPad (iOS):
1. Откройте веб-приложение NESTA в браузере **Safari**.
2. Нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх внизу экрана).
3. Прокрутите список вниз и выберите **«На экран "Домой"»** (*Add to Home Screen*).
4. Нажмите **«Добавить»**. На рабочем столе появится иконка NESTA. Приложение запускается в полноэкранном нативном режиме без рамок браузера.

### На Android (Samsung, Xiaomi, Pixel и др.):
1. Откройте NESTA в браузере **Google Chrome**.
2. Во всплывающем баннере внизу нажмите **«Установить приложение NESTA»** (или в меню «три точки» выберите *«Установить приложение»*).
3. Иконка добавится в меню приложений смартфона.

## 3. Сборка нативного приложения (Capacitor: Android & iOS)

В проекте уже создан конфигурационный файл `capacitor.config.ts`.

### Шаг 1. Установка зависимостей Capacitor (при необходимости сборки в APK/IPA):
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
```

### Шаг 2. Инициализация и генерация нативных проектов:
```bash
# 1. Сборка веб-бандла
npm run build

# 2. Добавление платформы Android
npx cap add android

# 3. Добавление платформы iOS (требуется macOS и Xcode)
npx cap add ios

# 4. Синхронизация ассетов и плагинов
npx cap sync
```

### Шаг 3. Запуск и сборка Android APK:
```bash
npx cap open android
```
Откроется **Android Studio**:
- Выберите пункт меню **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** для получения готового файла для установки на смартфон.
- Или **Build -> Generate Signed Bundle / APK** для публикации в **Google Play Store**.

### Шаг 4. Запуск и сборка iOS App:
```bash
npx cap open ios
```
Откроется **Xcode**:
- Выберите ваш аккаунт Apple Developer в секции *Signing & Capabilities*.
- Подключите iPhone кабелем и нажмите кнопку **Run (Cmd + R)** или выберите симулятор iPhone 16 Pro.
- Для публикации выберите **Product -> Archive** для отправки в **App Store Connect / TestFlight**.
